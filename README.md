# Reg-Intel Inject

Interactive mock simulator for exploring datacenter supply-chain exposure under U.S. telecommunications, semiconductor, and national-security regulations.

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://127.0.0.1:4173/index.html`.

## Included views

- **Overview** — confirmed, adopted, proposed, and reported regulation context
- **Simulation** — illustrative timeline, heatmap, BOM exposure, and mitigation trace
- **Inject library** — regulation evidence records
- **BOM import** — planned BOM upload and field mapping workflow
- **Decision memo** — printable scenario summary

## Scope

This is an educational planning simulation, not legal advice. Regulatory status and the included mock BOM are illustrative. Re-check live FCC, DoD, Congress, and federal-register sources before relying on a result.
